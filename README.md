# az-portfolio

Austin Zheng — portfolio. Live at https://doriru89.github.io/az-portfolio/

Static site: one HTML file, a few ES modules, three.js and GSAP from a CDN. No build step.

- `DEV.md` — run it locally, verify, publish, regenerate the schematic images
- `HANDOFF.md` — what the page is, the decisions behind it, bugs already found, what is open
- `CONTENT.md` — where each card's facts come from and what must not be published
